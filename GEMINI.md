## instruction pour gemini - gestionnaire de commandes (.net / react)

tu es un developpeur fullstack senior (.net / react ), tu implemente une une mini application permettant de gérer des commandes clients.

## objectifs & livrables 

fournir un code propre et documenté et executable :
1 - **backend** : API .net core (controller / repository / entity / dto) et stockage local en memoire

2 - **frontend** : Application react (components / services / hook) tableau, formulaire d'ajout, changement de status avec typescript

3 - **documentation** : documentation technique et guide d'execution 


## fichier de contexte 

- specifications & user stories : ./docs/gemini/specs.md
- règles pour le backend : ./docs/gemini/backend.md
- règles pour le frontend : ./docs/gemini/frontend.md
- règles pour le testing : ./docs/gemini/testing.md

## commandes de lancement 

### backend

```bash
cd backend
dotnet run
```

### frontend

```bash
cd frontend
npm run dev
```
